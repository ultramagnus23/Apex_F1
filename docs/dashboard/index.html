How the pace model was checked

Each dot is the share of held-out laps that fell inside the model's 90% predictive interval. A calibrated model sits on the dashed 90% line. Whole-stint holdout is the test that matters for driver comparisons, because it includes stint-to-stint variation. Forward prediction (fit early laps, predict the end of the race) undercovers, so the model is not a forecast tool.

About

Apex turns public Formula 1 timing and telemetry into analysis that states what it can and cannot conclude. Every statement is tagged.

  • OBSERVED the data show it beyond measurement noise and it is stable across analysis choices.
  • HYPOTHESIS consistent with the data; the cause is not established.
  • INCONCLUSIVE within noise or unstable.
  • UNKNOWN public data cannot establish it.

Limits: qualifying and race sessions from 2025 and 2026 only. Public telemetry has no tyre temperature, fuel mass, ERS state or setup. Race pace is not modelled for wet or very noisy races. See the repository documentation for methods and validation.
