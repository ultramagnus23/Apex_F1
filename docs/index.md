# Apex

Reproducible, epistemically honest analysis of public Formula 1 timing and telemetry.
Every output claim is tagged **OBSERVED**, **HYPOTHESIS**, **UNKNOWN** or **INCONCLUSIVE**.

Apex compares laps, measures how much of each difference is real, and stress-tests every conclusion
under 81 analysis configurations. It is at **Phase 3 of 5**. See [Status](STATUS.md).
