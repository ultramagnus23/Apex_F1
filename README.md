# Apex — Motorsport Performance Intelligence

Open-source toolkit that turns public Formula 1 timing and telemetry into reproducible,
validated performance analysis. Every claim is tagged **OBSERVED**, **HYPOTHESIS** or **UNKNOWN**.

> Status: Phase 2 (alignment, deltas, corners). Start with
> [case study 01](docs/CASE_STUDY_01.md), then [methodology](docs/METHODOLOGY.md),
> [validation](docs/VALIDATION.md) and the [data contract](docs/DATA_CONTRACT.md).

```bash
uv run apex compare 2026 Austin Q ANT VER --phase 3
```

Unofficial project, not associated with Formula 1 companies. Data via FastF1 and OpenF1.
